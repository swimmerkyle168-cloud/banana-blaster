1. Drop Skills (8)

HOW DROP SKILLS WORK (our own system - inspired by Kirby 64):
Drop skills drop from enemies as floating pickups. Walk over one to pick it up (when slots are unlocked). You have 2 slots (dual skills). Two DIFFERENT skills = a Power Combo (28 pairs, stronger than either single, new effect). Two of the SAME skill = a self-combo (8, stronger version of that skill). Right-click locks the dual slots (floating skills will NOT be picked up - keeps the combo you like). Right-click again unlocks (so you can switch). No grenade - Q does nothing (kyle: "Q throws a grenade makes no sense"). Kirby 64 showed us two abilities can combine into a new one - that was the inspiration (kyle enjoyed the game). But ours is our own way, and it is SIMPLE: pick up, right-click to lock, right-click to unlock. That is the whole system.

Each skill = one sprite + one colour + one overlay silhouette (P1) + one effect.

Deterministic traits (named / set items)

LOCKED RULE: the same named / set item ALWAYS has the same traits (hand-written, thematic to the set / item). Random padding is REMOVED for named / set items only (enforceAffixCounts skips unique / mythic / set). Ordinary (common / uncommon / rare) items are still procedurally generated with random affixes. Themes: Sunfire items carry fire, Frostbound carry frost, Moonfang carry swift / sharp / vamp / quick, Venom carry swift / sharp / vamp / pierce, Tempest carry charge / swift, Void carry void-themed traits.

Slots

3 equipment slots: LEFT HAND, RIGHT HAND, NECKLACE. Only equipped items grant stats/traits/set bonuses. 2 drop-skill slots. 6 inventory slots (stash, MAX_STASH=6). Stash items grant NOTHING until equipped. Pickup magnet/AoE is FIXED and can NEVER be changed by any item, skill, trait, set bonus, or vendor purchase.

Auto-Weapons: equipped items attack on their own

RULE: With NO equipment, the player only has left-click drop skills (bananas, aimed with the mouse). When an item is EQUIPPED, the player ALSO gets that item's weapon attack - AUTOMATIC, NOT controlled by the player. You control the drop skill projectiles (bananas). You do NOT control the weapon projectiles (they fire on their own timers). That way the player has more projectiles to shoot out, without more buttons.
DAMAGE: Weapon projectile damage = rarity base x type damage multiplier x variance. Rarity base: common=1, uncommon=1, rare=2, unique=2, mythic=3, set=3. Variance: rolled ONCE at drop (0.85x-1.15x, +/-15%) and stored on the item, so two copies of the same weapon can hit slightly differently. Example (nominal variance 1.00): a mythic sword = 3 x 1.5 x 1.00 = 4.5 dmg (3.83-5.18 with variance). A common dagger = 1 x 0.7 x 1.00 = 0.7 dmg. Wave-found does NOT affect damage (auto weapons get no wave boost - looting items is the point).
SPEED (cooldown between auto-attacks, frames @60fps): common=120 (slowest), uncommon=120 (slowest), rare=100 (a bit faster), unique=80 (even faster), mythic=60 (faster than unique), set=45 (fastest). Rarity makes weapons BOTH stronger AND faster. Then the weapon TYPE modifies it (see table): a sword is slower than a dagger, a dagger is quicker.
SHIELD BUBBLE CD: After the bubble pops (blocks its hits), it goes on cooldown before it comes back. CD by rarity: common/uncommon=10s, rare=8s, unique=6s, mythic=5s, set=4s. Two shields = the bubble blocks 2 hits, CD = the better (shorter) shield's CD. Bubble does NOT stack with the BANANA SHIELD vendor item (that is a separate bubble with its own 20s CD).
WEAPON TYPES ARE THEMED AROUND THEMSELVES: each weapon type has its own damage + speed multiplier, on top of rarity. A sword does MORE damage than a dagger but is SLOWER. A dagger does LESS damage but is QUICKER. Final damage = rarity base x type damage multiplier x variance (variance rolled once at drop, 0.85x-1.15x, stored on the item). Final cooldown = rarity cooldown x type speed multiplier.

8. Bosses + Boss Skills

Each boss has 3 base attacks + 1 SIGNATURE (its defining move). Rotation: P1 (NG+0) = [base0, base1, signature] — P1 withholds the 3rd base attack. P2/P3 (NG) = [base0, base1, base2, signature] — NG restores the withheld base. The signature is a ROTATION member from fight start (100% HP), never withheld, NOT a one-time 50% HP trigger. Boss HP, projectile damage, and contact damage scale by WAVE with a HYBRID RAMP after wave 12 (see Formulas). Bosses have an element, a weakness (2x damage), and a resistance (0.5x damage). HP is NEVER shown. Actual boss HP = bossHPForWave(wave) × 1.6^ngp × 0.75 × 1.25 × tough (see §12); the hp field in the boss definitions is legacy and is NOT used at runtime. Waves 30–31 bosses also use ONE-HIT KILL (see Telegraphs). Boss ATTACKS: see §21 (theme-specific spec, IMPLEMENTED 2026-10-14). The game now runs the theme-specific attacks (all 84 in execBossAtk; verified via forced attack cycles, 0 frame errors).

STACKING RULE (all +percentage bonuses): +percentage bonuses stack with DIMINISHING RETURNS (harmonic). 2 stacks of +50% = +50% + 50%*(1/2) = +75%, NOT +100%. 3rd stack = +50%*(1/3). harm(n) = 1 + 1/2 + 1/3 + ... + 1/n. Bonus = base * harm(n). Vendor perm effects (max stacks) use harm(). Gear % stats (items + traits) use harmonic weighting (largest counts fully, 2nd half, 3rd third). Flat bonuses (+1 max HP, +1 pierce, durations) stay linear. Exponential mods (SWIFT HANDS 0.9^n, IRON SKIN 0.75^n, ADRENALINE 0.85^n) are already diminishing - left as-is. Why: vendor max perm effects can be REALLY strong if percentages stack linearly (10 stacks of +15% = +150%). Harmonic keeps them strong but sane.

14. Design Philosophy: Build vs Skill

Standing balance principle. It governs tuning (including the NG curve in Section 12) but is not itself a mechanic.

Good build deserves to snowball. Power fantasy is earned through build quality — the right gear, the right choices, the right loot. A player who builds well SHOULD snowball.

Crap build loses — unless the player is good at dodging. Skill is the fallback that compensates for a bad build. Every mechanic stays dodgeable (telegraphed, fair patterns) so a skilled player with a weak build can still win.

Two paths to winning: build well, or dodge well. Build + dodge together = snowball.

This section REPLACES the old generic boss attack descriptions (fan/ring/slow/beam/freeze/meteors) — the appendix describes the theme-specific attacks now in the game. The generic attacks are gone.

Source: Current regulars are generic (bFan/bRing/bMeteor/bSlow/bCracks/bBurn/spin, recolored per boss). Current signatures are a mix — several are already theme-specific (Brinebeard Tidal Wave, Moonhowl Blood Moon, Vespa Hive, Dreadnought Siege, Pip Betrayal, Librarian Silence) and are kept/upgraded; the rest are rebuilt.

Rules kept: 4 attacks per boss (3 regular + 1 signature); telegraph shape = BOSS_SHAPE[bossId] (hitbox matches draw); damage = atkMul × base boss projectile damage (DoT ticks = 0.5× base × atkMul per tick); windup = 180f (3s, NG −60f in P2/P3 via ngTeleT); rotation cadence = boss attack timer. Stats unchanged (tough/atkMul/element/weak/resist untouched — mechanics only). Total: 84 attacks (21 groups × 4; Pip & Pop share 4 duo attacks = 22 bosses).

Attacks that could NOT be made pure-damage theme-specific (and why)

  1. Conductor A3 CRESCENDO — A buff (accelerates the next 3 attacks), no direct damage. Theme-specific (the music gets faster) but it is a setup attack, not a hit. Kept because the orchestra-speeds-up mechanic only works as a buff.
